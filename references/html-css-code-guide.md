# HTML/CSS Code Guide

## 목적
이 문서는 랜딩페이지 기획 결과를 실제 HTML/CSS 소스로 변환할 때 사용하는 기준이다.

## 기본 원칙
- 사용자가 바로 복사해서 사용할 수 있는 완성형 코드를 제공한다.
- 특별한 요청이 없으면 단일 HTML 파일로 작성한다.
- CSS는 `<style>` 태그 안에 포함한다.
- JavaScript는 꼭 필요한 경우에만 사용한다.
- 외부 라이브러리 없이도 작동해야 한다.
- 모바일 화면에서 먼저 깨지지 않도록 구성한다.

## 코드 작성 기준
- HTML5 시맨틱 태그를 사용한다.
- 섹션별 주석을 넣어 수정하기 쉽게 만든다.
- 클래스명은 의미가 명확해야 한다.
- 색상, 여백, 라운드값은 CSS 변수로 관리한다.
- 이미지 경로는 사용자가 쉽게 바꿀 수 있게 작성한다.

## 기본 색상 방향
AI, 교육, 컨설팅, 웹기획 관련 랜딩페이지는 다음 방향을 우선한다.

- 배경: 화이트 또는 라이트 그레이
- 텍스트: 진한 네이비 또는 다크 그레이
- 포인트: 스카이블루, 블루, 소프트 퍼플
- 카드: 화이트 배경 + 옅은 테두리 + 부드러운 그림자

## 기본 섹션 구조
1. Header
2. Hero
3. Problem
4. Solution
5. What You Get
6. Differentiation
7. Process
8. FAQ
9. CTA
10. Footer

## 반응형 기준
- 1024px 이상: 데스크톱 레이아웃
- 768px 이하: 태블릿/모바일 레이아웃
- 480px 이하: 작은 모바일 최적화

## 피해야 할 코드
- 불필요하게 복잡한 중첩 구조
- 의미 없는 클래스명
- 수정하기 어려운 인라인 스타일 남발
- 지나친 애니메이션
- 외부 CDN 의존
- 너무 작은 글자 크기
- 모바일에서 2단/3단 레이아웃 유지

## 출력 시 포함할 설명
HTML/CSS 코드를 제공한 뒤에는 다음을 짧게 안내한다.

1. 텍스트 수정 위치
2. 색상 수정 위치
3. 이미지 경로 수정 위치
4. CTA 링크 수정 위치
5. 모바일 대응 여부

   # HTML/CSS Code Guide for Soul AI Work

## 목적

이 문서는 Soul AI Work 스타일의 랜딩페이지를 HTML/CSS로 생성할 때 사용하는 디자인 및 코드 기준이다.

랜딩페이지는 다음 목적을 가진다.

- AI 기반 비즈니스 상담
- 웹기획 서비스 소개
- 브랜드 문구 정리
- 교육 과정 홍보
- 자동화 실습 강의 소개
- 1:1 컨설팅 상품 안내
- 개인 브랜드 신뢰 형성
- 상담 신청 전환

## 기본 색상 시스템

HTML/CSS 생성 시 특별 요청이 없으면 아래 색상 변수를 기본으로 사용한다.

```css
:root {
  --bg: #f7f9fc;
  --surface: #ffffff;
  --surface-soft: #f0f9ff;
  --text: #1f2937;
  --heading: #111827;
  --muted: #6b7280;
  --primary: #38bdf8;
  --primary-dark: #0284c7;
  --primary-soft: #e0f2fe;
  --accent: #6366f1;
  --border: #e5e7eb;
  --radius: 24px;
  --shadow: 0 20px 60px rgba(15, 23, 42, 0.08);
  --max: 1120px;
}
