# HTML/CSS Code Guide

## 목적
이 문서는 랜딩페이지 기획 결과를 실제 HTML/CSS 소스로 변환할 때 사용하는 기준이다.

## 기본 원칙
- 사용자가 바로 복사해서 사용할 수 있는 완성형 코드를 제공한다.
- 특별한 요청이 없으면 단일 HTML 파일로 작성한다.
- CSS는 `<style>` 태그 안에 포함한다.
- JavaScript는 꼭 필요한 경우에만 사용한다.
- 외부 라이브러리 없이도 작동해야 한다.
- 모바일 화면에서 먼저 깨지지 않도록 구성한다.

## 코드 작성 기준
- HTML5 시맨틱 태그를 사용한다.
- 섹션별 주석을 넣어 수정하기 쉽게 만든다.
- 클래스명은 의미가 명확해야 한다.
- 색상, 여백, 라운드값은 CSS 변수로 관리한다.
- 이미지 경로는 사용자가 쉽게 바꿀 수 있게 작성한다.

## 기본 색상 방향
AI, 교육, 컨설팅, 웹기획 관련 랜딩페이지는 다음 방향을 우선한다.

- 배경: 화이트 또는 라이트 그레이
- 텍스트: 진한 네이비 또는 다크 그레이
- 포인트: 스카이블루, 블루, 소프트 퍼플
- 카드: 화이트 배경 + 옅은 테두리 + 부드러운 그림자

## 반응형 기준
- 1024px 이상: 데스크톱 레이아웃
- 768px 이하: 태블릿/모바일 레이아웃
- 480px 이하: 작은 모바일 최적화

## 피해야 할 코드
- 불필요하게 복잡한 중첩 구조
- 의미 없는 클래스명
- 수정하기 어려운 인라인 스타일 남발
- 지나친 애니메이션
- 외부 CDN 의존
- 너무 작은 글자 크기
- 모바일에서 2단/3단 레이아웃 유지
