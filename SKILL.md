## Core Principles

A good landing page must quickly answer:

1. What is this service?
2. Who is it for?
3. What problem does it solve?
4. What outcome does the visitor get?
5. Why should the visitor trust it?
6. What should the visitor do next?

Always prioritize:

- clear positioning
- specific customer pain points
- practical benefits
- credible differentiation
- strong CTA flow
- mobile readability
- copy that can be used directly on a real website
- HTML/CSS code that can be copied and implemented immediately

## Copywriting Rules

Use Korean.

Write in a professional but approachable tone.

Avoid excessive hype.

Good:

- AI를 업무에 어떻게 써야 할지 막막한 분들을 위해, 현재 업무 구조를 정리하고 바로 적용 가능한 활용 방향을 제안합니다.
- 도구를 많이 아는 것보다 중요한 것은, 내 업무와 비즈니스 구조 안에서 어디에 AI를 적용할지 판단하는 것입니다.
- 브랜드, 웹, 콘텐츠, AI 활용 방향을 함께 정리해 실무에 바로 적용 가능한 구조로 설계합니다.

Avoid:

- AI로 당신의 인생과 비즈니스를 완전히 바꿔드립니다.
- 최고의 AI 솔루션을 제공합니다.
- 혁신적인 미래를 선도합니다.
- 차원이 다른 경험을 제공합니다.

## HTML/CSS Output Principles

The generated code must be:

- practical
- clean
- responsive
- easy to edit
- compatible with general hosting environments
- usable in Cafe24, static hosting, or simple HTML pages
- written as a single HTML file when the user does not request file separation
- visually aligned with a modern Korean AI consulting and web planning brand

Prefer:

- semantic HTML5
- CSS variables
- responsive grid and flex layout
- mobile-first structure
- clear section comments
- accessible contrast
- readable class names
- no unnecessary external libraries
- simple and polished interaction
- lightweight CSS animation only when useful

Avoid:

- overly complex JavaScript
- unnecessary build tools
- React or framework code unless requested
- vague placeholder sections
- broken image paths
- excessive animation that hurts readability
- too many decorative elements
- unreadable low-contrast text
- desktop-only layout

```html
    /* CSS here */
  </style>
</head>
<body>
  <!-- HTML here -->
</body>
</html>
```

# Soul AI Work Visual Style

## Default Visual Direction

For HTML/CSS landing pages, use a clean and modern AI consulting style based on the Soul AI Work tone.

The design should feel:

- professional
- clear
- trustworthy
- practical
- light
- modern
- not too flashy
- suitable for AI consulting, web planning, education, and one-person business services

---

## Default Color System

Use these CSS variables unless the user requests different colors:

```css
:root {
  --bg: #f7f9fc;
  --surface: #ffffff;
  --surface-soft: #f0f9ff;
  --text: #1f2937;
  --heading: #111827;
  --muted: #6b7280;
  --primary: #38bdf8;
  --primary-dark: #0284c7;
  --primary-soft: #e0f2fe;
  --accent: #6366f1;
  --border: #e5e7eb;
  --radius: 24px;
  --shadow: 0 20px 60px rgba(15, 23, 42, 0.08);
  --max: 1120px;
}
```

---

## Layout Style

Use:

- light gray page background
- white card surfaces
- sky blue accent color
- deep gray or navy text
- rounded cards
- soft shadows
- spacious section padding
- clear CTA buttons
- grid-based card layout
- sticky or simple header when useful
- mobile-first responsive design

Preferred max width:

```css
--max: 1120px;
```

Preferred section spacing:

```css
.section {
  padding: 96px 0;
}
```

Mobile section spacing:

```css
@media (max-width: 768px) {
  .section {
    padding: 72px 0;
  }
}
```

---

## Typography Style

Use system Korean-friendly font stack:

```css
font-family: -apple-system, BlinkMacSystemFont, "Pretendard", "Noto Sans KR", "Segoe UI", sans-serif;
```

Headlines should be:

- bold
- concise
- clear
- slightly tight letter-spacing
- readable on mobile

Recommended headline style:

```css
h1 {
  font-size: clamp(2.7rem, 6vw, 5rem);
  line-height: 1.08;
  letter-spacing: -0.06em;
}
```

Recommended section title style:

```css
.section-title {
  font-size: clamp(2rem, 4vw, 3.25rem);
  line-height: 1.2;
  letter-spacing: -0.04em;
}
```

---

## Button Style

CTA buttons should be obvious and conversion-focused.

Use:

```css
.btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  padding: 15px 24px;
  border-radius: 999px;
  font-weight: 700;
  background: var(--primary-dark);
  color: #ffffff;
  box-shadow: 0 12px 30px rgba(2, 132, 199, 0.25);
}
```

Mobile rule:

```css
@media (max-width: 480px) {
  .btn {
    width: 100%;
  }
}
```

---

## Visual Component Style

Use cards like:

```css
.card {
  background: var(--surface);
  border: 1px solid var(--border);
  border-radius: var(--radius);
  padding: 32px;
  box-shadow: var(--shadow);
}
```

Use soft visual blocks like:

```css
.visual-box {
  background: linear-gradient(135deg, #ffffff, #e0f2fe);
  border-radius: 36px;
  border: 1px solid var(--border);
  box-shadow: var(--shadow);
}
```

---

## Responsive Rules

Use breakpoints:

```css
@media (max-width: 900px) {
  .hero-grid,
  .grid-2,
  .grid-3 {
    grid-template-columns: 1fr;
  }
}
```

```css
@media (max-width: 480px) {
  .container {
    width: min(100% - 28px, var(--max));
  }
}
```

Mobile priorities:

- first CTA must be visible
- text must not be too small
- multi-column cards must become one column
- buttons should be full width
- section spacing should be reduced
- sticky navigation can hide links and keep only logo/CTA

## Cafe24 and Static Hosting Rules

When the user asks for Cafe24 or simple hosting compatibility:

- provide plain HTML/CSS
- avoid build tools
- avoid npm, React, Vue, Next.js unless requested
- use relative or absolute image paths that are easy to replace
- add comments for image path replacement
- keep CSS inside `<style>` unless the user requests separate files

Image path example:

```html
<img src="/soul/assets/img/example.jpg" alt="설명 텍스트" />
```

CTA link example:

```html
<a href="https://www.soul-aiwork.com/contact.html" class="btn">상담 신청하기</a>
```

---

## Code Quality Checklist

Before finalizing HTML/CSS output, verify:

- The HTML has valid structure.
- The CSS is included inside `<style>`.
- The layout works on desktop and mobile.
- The CTA buttons are visually clear.
- The section order supports conversion.
- The user can copy and paste the code immediately.
- Text is written in natural Korean.
- There are comments indicating major sections.
- Color variables are easy to modify.
- Image and CTA links are easy to replace.
- The page is usable without JavaScript.
- The first screen explains the offer clearly.
- The mobile layout does not break.
