# Soul Landing Page Planner Skill

## Purpose
This skill creates practical Korean landing page plans, section copy, UX structure, design direction, and conversion-focused messaging.

Use this skill when the user asks for:
- 랜딩페이지 기획
- 웹사이트 문구 작성
- 상세페이지 구조 작성
- 서비스 소개 페이지 작성
- 교육 과정 홍보 페이지 작성
- AI 컨설팅 랜딩페이지 작성
- HTML 섹션 구조 기획
- 반응형 웹 구성 설계
- CTA 문구 작성
- 웹페이지 와이어프레임 작성
- 홈페이지 Hero 문구 작성

## Core Principles

A good landing page must quickly answer:

1. What is this service?
2. Who is it for?
3. What problem does it solve?
4. What outcome does the visitor get?
5. Why should the visitor trust it?
6. What should the visitor do next?

## Recommended Section Structure

Use this default section order unless the user specifies otherwise:

1. Hero
2. Problem
3. Empathy
4. Solution
5. What You Get
6. Service or Course Details
7. Differentiation
8. Process
9. Case or Example
10. FAQ
11. Final CTA

## Output Rules

### For Full Landing Page Plan
Include:

1. 페이지 목적
2. 타깃 고객
3. 핵심 메시지
4. 전체 섹션 구조
5. 섹션별 문구 초안
6. 디자인 방향
7. CTA 문구 3종
8. 모바일 구성 포인트
9. 제작 체크리스트

### For Section Copy
For each section, provide:

- Section name
- Purpose
- Headline
- Subheadline
- Body copy
- CTA
- Visual direction

### For UX and Design Direction
Always include:

- layout suggestion
- visual hierarchy
- color mood
- image or icon direction
- responsive behavior
- trust-building elements
- CTA placement

## Copywriting Rules

Use Korean.

Write in a professional but approachable tone.

Avoid excessive hype.

Prefer clear and credible benefit statements.

Good:
- AI를 업무에 어떻게 써야 할지 막막한 분들을 위해, 현재 업무 구조를 정리하고 바로 적용 가능한 활용 방향을 제안합니다.

Avoid:
- AI로 당신의 인생과 비즈니스를 완전히 바꿔드립니다.

## CTA Rules

Create at least 3 CTA variations:

1. direct
2. soft
3. premium

Example:
- 상담 신청하기
- 내 업무에 맞는 AI 활용 방향 알아보기
- 1:1 AI 비즈니스 정리 상담 예약하기

## Quality Checklist

Before finalizing, check:

- Is the first screen clear?
- Is the target audience obvious?
- Is the pain point specific?
- Is the offer easy to understand?
- Are benefits concrete?
- Is the CTA visible and natural?
- Can this be converted into HTML?
- Is the mobile flow considered?
- Is the copy credible and not exaggerated?
