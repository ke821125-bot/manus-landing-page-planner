# Sample One-Page HTML Output

## 요청 예시
1:1 AI 비즈니스 정리 상담 상품 랜딩페이지를 HTML/CSS로 만들어줘.

## 출력 방향
- 단일 HTML 파일
- `<style>` 내부 CSS 포함
- 모바일 반응형
- 라이트 그레이 배경
- 스카이블루 포인트
- 신뢰감 있는 컨설팅 페이지 톤
- Hero, Problem, Solution, Benefits, Process, FAQ, CTA 포함

## 코드 생성 시 포함할 안내
HTML/CSS 출력 후 다음 안내를 덧붙인다.

### 수정 위치 안내
- 제목과 문구는 각 section 내부 텍스트를 수정한다.
- 색상은 `:root`의 CSS 변수에서 수정한다.
- 버튼 링크는 `href="{{CTA_LINK}}"` 값을 실제 상담 신청 링크로 교체한다.
- 이미지는 필요 시 `.visual-box` 영역에 `<img>` 태그를 추가한다.

### 적용 방법
1. 코드를 `index.html`로 저장한다.
2. 브라우저에서 열어 화면을 확인한다.
3. 문구와 링크를 수정한다.
4. Cafe24 또는 일반 웹호스팅에 업로드한다.

### 체크리스트
- 모바일에서 CTA 버튼이 잘 보이는가?
- 첫 화면에서 서비스가 바로 이해되는가?
- 문제 제기와 해결 방식이 자연스럽게 이어지는가?
- 상담 신청 버튼이 충분히 명확한가?
